# Security Policy

PDF Editor processes every file on the user's device. Privacy is the main promise of this app, so security reports are taken seriously.

## Supported versions

Only the latest release (and the live web app) gets security fixes.

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately instead:

1. Go to the [Security tab](https://github.com/krishnakantnagina/pdf-editor-app/security) of this repository.
2. Click **Report a vulnerability**.

Please include what is affected, how to reproduce it, and what an attacker could do with it. You should get a reply within 7 days.

Examples of what counts:

- any way a user's PDF or its contents could be sent off the device;
- redaction that leaves the "removed" text recoverable in the saved file;
- script injection through a crafted PDF, image or file name.
